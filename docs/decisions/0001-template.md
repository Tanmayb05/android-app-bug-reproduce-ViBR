# ADR Template

Use this template when making significant architectural decisions. Save as `000N-decision-name.md` in this folder.

## Title

Brief decision name (e.g., "Use Mock ADB for Unit Tests", "Screen Parser Design").

## Status

- **Proposed** — under discussion
- **Accepted** — approved, now guiding
- **Deprecated** — old decision, replaced by newer ADR
- **Superseded by** — link to newer ADR if deprecated

## Context

Why did we need to make this decision? What problem were we solving?

- Background
- Requirements
- Constraints
- Stakeholders

## Decision

What we chose and why.

## Alternatives Considered

What else did we evaluate?

For each alternative:
- Pros
- Cons
- Why we didn't choose it

## Consequences

Impact of this decision.

### Positive

- What got better?
- What became easier?

### Negative

- Trade-offs?
- What became harder?
- Ongoing costs?

Links to other ADRs:
