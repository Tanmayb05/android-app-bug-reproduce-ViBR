    - DINO only detected 0-10 (11 boxes total, indices 0-10)
  • Segment 2: LLM selects [1] but annotation says "No relevant regions"

Real issue:
  • Line 197 filter: if r["index"] in relevant_indices
  • When LLM returns index 11 but DINO only has 11 detections [0-10]:
    - Key 11 doesn't exist
    - Annotation image is blank
    - LLM gets blank image, doesn't know valid regions
    - LLM guesses wrong

Two-liner explanation:
  • Segment 1: DINO found 11 boxes [0-10], LLM returns index 11 (doesn't exist)
    - Annotation filter fails silent
  • Segment 2: DINO found boxes, LLM returns index 1
    - Index 1 not in DINO results (filtered during detection)
